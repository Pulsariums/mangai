## Kurulum

### Temel Kurulum (FAZ 1 için)
```bash
pip install -r requirements.txt
```

### GPU Desteği (Opsiyonel, Hızlandırılmış OCR için)
```bash
# NVIDIA GPU varsa
pip uninstall paddlepaddle
pip install paddlepaddle-gpu
```

### Tam Kurulum (Tüm Fazlar için)
```bash
pip install -r requirements_full.txt
```

## Notlar

1. **PaddleOCR İlk Çalıştırma:** İlk çalıştırmada model dosyalarını otomatik indirir (~200MB). İnternet bağlantısı gereklidir.

2. **Manga-OCR Alternatifi:** Eğer sadece Japonca manga çevirecekseniz, `manga-ocr` daha iyi sonuç verebilir. Ancak PaddleOCR çok dilli destek sağlar.

3. **Performans:** Büyük görseller için GPU önerilir. CPU'da da çalışır ancak yavaş olabilir.

4. **Sistem Gereksinimleri:**
   - Minimum RAM: 4GB
   - Önerilen RAM: 8GB+
   - Disk: 1GB+ (model dosyaları için)
